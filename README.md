# Snake Arcade Game

This web application is a classic snake arcade game featuring score tracking and responsive controls.

## Overview

The application runs a standard grid simulation on an HTML canvas using JavaScript interval loops. It tracks snake segment coordinates, processes directional input safely, and checks for collision events against walls and self.

## Highlights

- Classic arcade gameplay mechanics
- High score persistence using storage
- Keyboard and touchscreen controls
- Clean flat user interface

## Getting started

Open `index.html` in a browser. No install or build step.

## Layout

- `index.html`: Main markup structure and container elements
- `style.css`: Complete design using mandated variables
- `script.js`: Game loop state logic and input listeners
